接入

<repositories>
  <repository>
    <id>fakehappy</id>
    <url>https://happywithmin.github.io/FakeHappy/maven</url>
  </repository>
</repositories>

<dependency>
  <groupId>maybe_c</groupId>
  <artifactId>fakehappy-api</artifactId>
  <version>1.2</version>
  <scope>provided</scope>
</dependency>
repositories {
    maven { url = uri("https://happywithmin.github.io/FakeHappy/maven") }
    maven { url = uri("https://repo.papermc.io/repository/maven-public/") }
}
dependencies {
    compileOnly("maybe_c:fakehappy-api:1.2")
}

作用域必须是 provided / compileOnly，不要把它打进你自己的 jar。 打进去会和服务器上那份撞，症状是随机的 NoSuchMethodError，或者拿到一个永远是空的服务。
也不要去接服务器上的 FakeHappy 本体。那是实现，内部随时重写；接了就会在某次升级之后莫名其妙地炸。 fakehappy-api 是纯契约 —— 接口、事件、枚举、规范清单，零实现，运行时由本体提供。
