FakeHappy 开发者接入指南

本文介绍小游戏和附属插件接入 FakeHappy 的方式。FakeHappy 提供文本、界面、生命周期、奖励、组队和跨服服务。

你接的是 fakehappy-api

<dependency>
  <groupId>maybe_c</groupId>
  <artifactId>fakehappy-api</artifactId>
  <version>1.4.6</version>
  <scope>provided</scope>
</dependency>

fakehappy-api 包含公开接口、事件、枚举和规范，运行时由服务器上的 core 提供。 只添加 API 依赖，使用 provided / compileOnly；不要依赖 core 或把 API 打包进拓展 jar，以免发生类加载冲突。

仓库地址、源码和 Javadoc 在 fakehappy-sdk-1.4.6.zip 中；SDK 也提供离线 jar、文档和示例。详见 接入与工程结构。

从哪开始

第一次接入：接入 → 小游戏 → 奖励结算。

示例：fakehappy-example 中的 ClickRaceGame 参与主构建，SDK 中位于 example/。

给 AI 用：SDK 包里的 AGENTS.md（短入口，含必须项清单）和 FAKEHAPPY-SPEC.md（全量规范）。也可以请服主在服务器上导出一份。 两份规范由 SpecCatalog 生成，与服务器合规检查使用同一来源。
