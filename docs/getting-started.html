接入与工程结构

FakeHappy 开发文档的一部分。索引在 开发文档首页。

1. SDK 内容

获取并解压 fakehappy-sdk-1.4.6.zip：

fakehappy-sdk-1.4.6/
├── README.md                              从哪开始
├── libs/
│   ├── fakehappy-api-1.4.6.jar              API
│   ├── fakehappy-api-1.4.6-sources.jar      源码
│   └── fakehappy-api-1.4.6-javadoc.jar
├── AGENTS.md                              给 AI 的短入口，含必须项清单
├── FAKEHAPPY-SPEC.md                      全量规范
├── DEVELOPERS.md + docs/                  这一份文档
└── example/                               参照实现，解压即可 mvn package

小游戏依赖公开 API；参照实现位于 example/。

1.4.6 已发布到公开 Maven 仓库，按下面的依赖配置即可；连不上仓库时安装 SDK 的 libs/。

2. 接入

2.1 依赖

从静态仓库解析：

<repositories>
  <repository>
    <id>fakehappy</id>
    <url>https://happywithmin.github.io/FakeHappy/maven</url>
  </repository>
  <repository>
    <id>papermc-repo</id>
    <url>https://repo.papermc.io/repository/maven-public/</url>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>maybe_c</groupId>
    <artifactId>fakehappy-api</artifactId>
    <version>1.4.6</version>
    <scope>provided</scope>
  </dependency>
</dependencies>

SDK 构建时会填入仓库地址。仓库同时提供 sources 和 Javadoc，可由 IDE 下载。

无法访问仓库时，可安装 libs/ 中的离线文件：

mvn install:install-file \
  -Dfile=libs/fakehappy-api-1.4.6.jar \
  -Dsources=libs/fakehappy-api-1.4.6-sources.jar \
  -Djavadoc=libs/fakehappy-api-1.4.6-javadoc.jar \
  -DpomFile=libs/fakehappy-api-1.4.6.pom \
  -DgroupId=maybe_c -DartifactId=fakehappy-api -Dversion=1.4.6 -Dpackaging=jar

安装后可移除仓库配置，保留相同依赖坐标。

Gradle 的话把 libs/ 拷进你的工程：

dependencies {
    compileOnly(files("libs/fakehappy-api-1.4.6.jar"))
}

只依赖 fakehappy-api，作用域使用 provided / compileOnly。 不要依赖 core 或把 API 打包进自己的 jar，以免与服务器提供的类冲突。

2.2 plugin.yml

depend: [FakeHappy]        # 硬依赖，保证加载顺序
# 或
softdepend: [FakeHappy]    # 软依赖，自己判空

2.3 取服务

HappyApi api = Happy.api();        // 硬依赖用这个，拿不到会抛异常
HappyApi api = Happy.apiOrNull();  // 软依赖用这个

使用时重新取服务；内部缓存会随核心重载失效。

2.4 你能从 HappyApi 拿到什么

api.text()        文本：三语法混写与文本安全      docs/02
api.ui()          菜单：Dialog 与箱子共用一套按钮  docs/03
api.games()       小游戏注册与生命周期            docs/04
api.rewards()     发货币 / 等级 / 积分           docs/05
api.economy()     读余额、收报名费                docs/05，可能为 null
api.settlement()  按名次结算奖励                  docs/05
api.party()       全服组队，编队形态              docs/06
api.chat()        局内聊天分频（队伍 / 全局 / 观战）docs/04
api.network()     跨服：房间、送人、自定义频道      docs/07
api.data()        战绩与跨服偏好                  docs/04
api.modules()     可选：把功能注册成可开关的模块    docs/08

economy() 在经济模块未启用时可能返回 null，必须判空。其他服务返回非空实现；后端不可用时按各接口约定返回空结果或失败状态。
