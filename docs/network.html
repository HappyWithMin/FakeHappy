8. 跨服

NetworkService net = api.network();
if (!net.isAvailable()) { /* 跨服层不可用 */ }

跨服层不可用时整体降级：查询返回空结果、上报静默丢弃、切服退回 BungeeCord 插件消息。所以这套 API 在单机开发环境下全都能调，只是什么也不会发生 —— 小游戏不需要为「这个子服有没有接跨服层」写两套代码。

net.rooms("spleef").thenAccept(rooms -> ...);       // 回调在异步线程！
net.findBestRoom("spleef").thenAccept(...);
net.sendToServer(player, "minigame-2");
net.publish("myspleef", json);                       // 频道名会自动加上框架的前缀，不会和别的插件撞
var sub = net.subscribe("myspleef", payload -> ...);

送人

sendToServer(player, 子服) 只能送本服在线的人，发出去就不管了。要送别的子服上的人、或者要知道送没送到，用 send：

net.send(List.of(uuidA, uuidB), "主大厅").thenAccept(result -> {
    // 回调在 IO 线程。每人一条：MOVED / ALREADY / FAILED（满人、被准入锁拦下……看 message）/ NOT_FOUND（不在线）
    for (var e : result.entries()) { ... }
});

各代理处理自己手上的人，最多等 12 秒；一次最多 500 人。不发活动入口邀请，被准入锁锁着的子服照样拦名单外的人。

subscribe 返回的句柄必须在你的插件卸载时 cancel()，否则订阅线程会一直 持有你的回调（连带整个插件类加载器）—— 这是重载后内存涨的典型原因。

房间预约

代理会先给房间预约名额（20 秒内有效）。超过容量时退回名额并选择其他房间；玩家到达后转换预约，未完成的预约到期释放。 带队排队一次预约整队人数，容量不足时整队换房间。
