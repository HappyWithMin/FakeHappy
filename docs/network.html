8. 跨服

NetworkService net = api.network();
if (!net.isAvailable()) { /* 跨服层不可用 */ }

跨服层不可用时整体降级：查询返回空结果、上报静默丢弃、切服退回 BungeeCord 插件消息。所以这套 API 在单机开发环境下全都能调，只是什么也不会发生 —— 小游戏不需要为「这个子服有没有接跨服层」写两套代码。

net.rooms("spleef").thenAccept(rooms -> ...);       // 回调在异步线程！
net.findBestRoom("spleef").thenAccept(...);
net.sendToServer(player, "minigame-2");
net.publish("myspleef", json);                       // 使用公开自定义频道
var sub = net.subscribe("myspleef", payload -> ...);

subscribe 返回的句柄必须在你的插件卸载时 cancel()，否则订阅线程会一直 持有你的回调（连带整个插件类加载器）—— 这是重载后内存涨的典型原因。

房间预约

房间预约由框架管理容量与超时。带队排队一次预约整队名额，容量不足时选择其他房间；未完成的预约自动释放。拓展通过 NetworkService 读房间、排队和转服，不操作内部预约键。
